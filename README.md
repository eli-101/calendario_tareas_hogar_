# Calendario de Tareas del Hogar

Calendario móvil (en español) para registrar quién hizo qué tarea del hogar y cuándo.

- **Inicio**: calendario estilo iOS, toca un día para ver o añadir tareas.
- **Estadísticas**: totales por persona y por tarea, filtrables por semana / mes / año y por tarea.
- **Ajustes**: gestiona la lista de tareas y personas.

Es una sola página HTML autónoma (sin build, sin dependencias de servidor) — se puede
desplegar tal cual en Vercel, GitHub Pages, Netlify, etc.

## Desarrollo local

Solo abre `index.html` en el navegador.

## Nota

Los datos se guardan únicamente en memoria del navegador (no hay backend ni
localStorage), así que se reinician al recargar la página. Es un prototipo/demo
de interfaz, no una app con persistencia real todavía.
